# Heart Disease Prediction using Machine Learning 🫀💻

This repository contains a Machine Learning project that analyzes clinical parameters (like age, cholesterol, blood pressure, etc.) to predict the presence of heart disease using classification foundations.

## 📊 Core Workflow Inside the Notebook:
- **Exploratory Data Analysis (EDA):** Visualizing features and examining correlations with heart disease targets.
- **Data Preprocessing:** Handled categorical variables (like `Sex`, `ChestPainType`, and `RestingECG`) using One-Hot Encoding and converted them to integers using `.astype(int)`.
- **Feature Scaling & Management:** Preparing the structured data vector columns for model ingestion.

## 🛠️ Requirements & Libraries Used:
- Python 3
- Jupyter Notebook
- Pandas & NumPy
- Scikit-Learn
- Matplotlib & Seaborn
